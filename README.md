# 🧪 Widget Lab

> **Inspect, preview, and debug your Yotpo widgets in real-time.** No more hunting through spreadsheets for widget IDs or copy-pasting HTML snippets. Welcome to your new favorite developer playground!

---

## 💭 Motivation

Let's be honest: **logging into Yotpo just to copy a widget instance ID is pain.**

Here's the problem Widget Lab solves:

- 🔐 **No More Yotpo Login Dance** — You shouldn't need to log into your Yotpo account, navigate three menus, find your widget, and copy the ID. That's tedious.
- 📝 **No More Notepad Hell** — Stop keeping placeholder widget HTML scattered in Notepad, Google Docs, or that one Slack thread from 2023.
- 🔄 **Copy-Paste Fatigue** — No more bouncing between Yotpo, Notepad, JSBin, JSFiddle, and your code editor. Get everything in one place.
- ⚡ **Instant Access** — Just your App Key and Product ID. That's it. Widget Lab handles the rest.

**The Aha Moment:** "What if I built a tool that just... did all this for me?" ✨

So here we are—a widget preview studio designed by someone who got tired of the tedious stuff. You're welcome. 😄

---

## ✨ Features

### 📱 Multi-Device Preview

- **Fluid Mode** — Full-width responsive preview
- **Desktop** — 1200px viewport
- **Tablet** — 768px viewport
- **Mobile** — 390px smartphone-style viewport (with phone bezel!)

Switch between layouts instantly to see how your widgets behave across all screen sizes.

### 🔍 Widget Inspector

- Browse all available widget types for your product
- Switch between widget instances with one click
- View live configuration details
- Copy widget IDs instantly (with satisfying "Copied!" feedback)

### 💻 Code Generator

- **HTML Embed Code** — Get the exact snippet you need to embed your widget
- **Raw Preview URL** — Open widgets in a standalone tab for testing
- Copy any code block to clipboard in a single click

### 🎛️ Live Controls

- **Real-Time Reload** — Refresh widgets without reloading the entire page
- **Open in New Tab** — Test widgets in isolation

## 🚀 Quick Start

### Get Your App Key & Product ID

First, head to your Yotpo dashboard and grab:

- Your **App Key** (find it in Settings → Developer)
- A **Product ID** from your catalog

### Open Widget Lab

Navigate to [Widget Lab](https://widgetlab.rterrado.com) and enter:

1. **App Key** — Your Yotpo application credentials
2. **Product ID** — The product you want to inspect

### Browse & Test

- Select different widget types from the left sidebar
- Switch viewport sizes to test responsiveness
- Copy HTML embed codes
- Reload and iterate

That's it! No setup, no build process, no friction. 🎉

## 💡 Tips & Tricks

**Pro Tip #1:** Bookmark your widget configurations by saving the URL. It includes your App Key and Product ID, so you can jump right back to where you were.

**Pro Tip #2:** Use the mobile viewport to catch responsive design issues early. Yotpo widgets are smart—watch them adapt!

**Pro Tip #3:** Open the raw preview in a new tab and use your browser's DevTools to debug CSS and JavaScript directly.
